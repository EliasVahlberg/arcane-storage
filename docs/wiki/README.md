# Arcane Storage

A guide for players. Everything here is about how the mod works in game, not how it is built.

Necesse gives you plenty of chests. It does not give you a way to see what is in all of them at once.
Arcane Storage adds a network you build, and one screen that shows everything on it.

## The short version

Build a **Storage Terminal**. Run **Arcane Conduits** from it to **Storage Units**. Open the terminal and you
see everything in every unit as one list you can search.

Put crafting stations into a **Station Unit** and the terminal can craft with them, taking materials from
anywhere on the network.

Add **Import** and **Export Buses** next to ordinary chests and items move in and out on their own.

That is the whole mod. Everything else is a bigger version of one of those four things.

## Two things to know before you start

**Everyone needs the mod.** If you play on a server, the server and every player connecting to it must have
Arcane Storage installed. It is not a client only mod.

**Do not uninstall with items inside.** Removing the mod removes its objects, and anything stored in them goes
too. If you want to stop using it, empty the network first. Every Storage Unit has an emptying button that
moves its contents into the rest of the network, which is also the easy way to move a unit.
