# Connectivity rules. Each group sits far enough from the others to be independent,
# so all of them share one server boot.
#
# Only unit counts are asserted here, deliberately: item totals are checked in
# multipath.txt, and `expect total` scans the whole level, so items placed by one group
# would leak into another group's assertion.

# --- A chain links through units, not just to the terminal (0,0) ---
#   T U U U U U
arcanestorage place terminal 0 0
arcanestorage place unit 1 0
arcanestorage place unit 2 0
arcanestorage place unit 3 0
arcanestorage place unit 4 0
arcanestorage place unit 5 0
arcanestorage expect units 0 0 5

# --- A diagonal neighbour is a separate network (0,10) ---
# Connectivity is orthogonal, so the unit at 1,11 touches the terminal only diagonally and
# must be excluded. The second unit is placed to the *west* on purpose: putting it at 1,10
# would make it orthogonally adjacent to 1,11, which would then legitimately join through
# it — correct behaviour, but it would stop this group testing the diagonal rule.
arcanestorage place terminal 0 10
arcanestorage place unit 1 11
arcanestorage expect units 0 10 0
arcanestorage place unit -1 10
arcanestorage expect units 0 10 1

# --- A one-tile gap is not bridged (0,20) ---
#   T . U
arcanestorage place terminal 0 20
arcanestorage place unit 2 20
arcanestorage expect units 0 20 0

# --- Breaking a unit mid-chain orphans everything beyond it (0,30) ---
#   T U U U   ->   T U . U
arcanestorage place terminal 0 30
arcanestorage place unit 1 30
arcanestorage place unit 2 30
arcanestorage place unit 3 30
arcanestorage expect units 0 30 3
arcanestorage break 2 30
arcanestorage expect units 0 30 1

# --- Two terminals on one chain see the same units (0,40 and 4,40) ---
# Each terminal resolves its own network independently, so this is expected to work with
# no extra code. Asserting it means a later change cannot break it unnoticed. Note the
# terminals do not conduct: 4,40 reaches the chain because 3,40 is a unit beside it.
arcanestorage place terminal 0 40
arcanestorage place unit 1 40
arcanestorage place unit 2 40
arcanestorage place unit 3 40
arcanestorage place terminal 4 40
arcanestorage expect units 0 40 3
arcanestorage expect units 4 40 3
